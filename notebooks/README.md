# Notebook Reading and Execution

Begin with 00_quickstart.ipynb; its synthetic inputs are included.
Then read 01_environment.ipynb to understand the empirical data contract.

To follow Chapter 2, read 03_pricing_risk.ipynb for pricing, 02_portfolio.ipynb
for allocation, and return to the risk/scenario part of notebook 03.
Chapter 3 is covered by 04_quantum_learning.ipynb.
Run 05_hardware_validation.ipynb after portfolio and learning, since it uses
their saved results.

The chapter notebooks need separately obtained market inputs; the quickstart
does not. Distributed outputs are cleared. Select the pinned Python kernel
and run each notebook from top to bottom.
